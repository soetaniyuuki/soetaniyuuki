### 🚀 About Me

QA Engineer based in Brazil with 2+ years of experience in manual and automated web testing across fintech applications and automotive dealership website migrations.  
I work with Playwright, Cypress, TypeScript, API testing, and SQL validation, collaborating in English with international teams.  
My work includes automation that reduced large-site migration review from approximately 4–5 hours to 30 minutes, including human validation, and producer/product test setup from approximately 20 minutes to under 2 minutes.  
Open to international remote opportunities in QA engineering, manual testing, and test automation.

🔭 &nbsp;I'm currently working on **CMS-to-live website validation and browser automation with Playwright and TypeScript.**  
👯 &nbsp;I'm looking to collaborate on **Web testing and test automation projects using Playwright and Cypress.**  
💬 &nbsp;Ask me about **Manual QA, exploratory testing, Playwright, Cypress, API testing, SQL validation, and CMS migration testing.**  
⚡ &nbsp;Fun fact: **I started in operations, automated workflows with Excel, and transitioned into software QA.**
